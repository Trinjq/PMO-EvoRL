# specs 目录指导

适用范围：`specs/` 及其子目录。

上级指导：[`../AGENTS.md`](../AGENTS.md)。全局开发规则：[`GLOBAL_RULES.md`](GLOBAL_RULES.md)。

## 目录职责

本目录只保存需要跨模块遵守的稳定规范，例如：

- PD-MORL 与 EvoRL 的总体架构和数据契约；
- 训练、评估和复现实验规则；
- 环境、偏好、Replay、网络与指标之间的公共约定；
- 已确认的论文与源码差异及其处理原则。

## 内容边界

- 不保存临时排查记录、运行日志、模型、Replay Buffer 或大型实验结果。
- 不重复模块 `AGENTS.md` 中只对该模块有效的细节。
- 尚未确认的行为必须标记为“待验证”，不得写成既定事实。
- 规范应说明适用范围、约束、理由和验证方式；能链接到现有规范时不要复制全文。

## 维护要求

- 新增规范文件后，必须更新根目录 [`AGENTS.md`](../AGENTS.md) 的索引。
- 规范影响某个模块时，该模块的 `AGENTS.md` 必须引用对应规范。
- 规范发生不兼容变化时，应在同一变更中更新受影响的代码、配置和测试。
